# halfsamoan

데스크톱에서 직접 쓸 도구를 만들고, 레이더와 오디오 신호를 다룹니다.

[PAPKER](https://papker.com)에서는 DOCX 논문의 인용·참고문헌·그림 번호를 검사할 수 있습니다.

## 데스크톱 도구

| 프로젝트 | 하는 일 |
|---|---|
| [matci](https://github.com/halfsamoan/matci) | GNOME 메모리 관측과 수동 창 닫기 |
| [Archsport](https://github.com/halfsamoan/archsport) | 축구 일정과 경기 점수를 표시하는 GNOME 노치 |
| [Focus Monitor](https://github.com/halfsamoan/gnome-focus-monitor) | 창 위치를 유지하며 모니터 사이의 포커스 전환 |
| [Qwen Local Desktop](https://github.com/halfsamoan/Qwen-Local-desktop-) | 로컬 모델과 프로젝트 파일로 대화하는 Linux 앱 |
